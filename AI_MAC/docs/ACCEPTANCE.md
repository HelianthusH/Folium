# 验收与记录

## 已在开发电脑执行

- Zephyr 4.2.0 交叉编译，目标 XIAO nRF52840 Sense。已生成 UF2。Windows x64 助手已打包。
- 10 个主机单元测试通过。覆盖 IMA 零输入、错误 CRC、元数据字节数、跨时间范围索引与重建、未校时会话、路径边界、损坏副本、断点导出、当前用户管道、草稿重复提交和编号冲突。
- 两个上游 WAV 通过本地 INT8 模型获得非空转写。未计算识别准确率或实时延迟分位数。
- 模块载板已输出 14 条直连网络与 28 个钻孔。外壳底盖已输出 STL。制板、装配公差及充放电需实物复核。

复跑命令为 python -m unittest discover -s tests -v 与 python tests/check_asr.py。使用装好 desktop/requirements.txt 的 Windows Python，模型存于 models/bilingual。测试产生的数据在临时文件夹。

## 当前边界

本机依赖卡来持久化状态，卡被移除时无法把故障写到该卡。无法验证的末段保留原件。文件系统损坏时先做只读备份。设备对启动周期内少量近期请求去重；重启后先查询状态。切段封存、计算 SHA-256、扫描低容量卡均占用时间，慢卡与 PCM 模式的实时余量需要台架测试。RTC 只有秒级精度，采样位置是同一会话内连续性的依据。实物没有电量计，状态中的电量为空。

自动订阅提供实时流。助手在一次已开始的听写中按采样位置检测缺块，重连后可从原 WAV 补取，恢复的文字保留为草稿。设备在本次开机中保留最近 16 次听写的定位信息。设备重启、换卡、窗口超期或整次听写都发生在断线期间时，通过 SD/USB 导出原录音。上台架时分别在按键按住、松开前、跨段时断开连接，核对文字、草稿次数和本机采样数。输入框兼容性受应用版本、辅助功能树及 Windows 权限影响，六组实测仍待执行。载板通过飞线连外围模块，机械固定和开孔以所购模块实物为准。
